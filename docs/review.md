# Проверка кода и документации перед v1.0.1

Проверены CLI, генератор, деривация, keystore, запись результатов, конфигурация, маскирование логов, автономный запуск EXE и workflow релиза. Проверка выполнялась на синтетических ключах, без использования пользовательских входных файлов.

| Находка | Исправление и проверка |
| --- | --- |
| Zap обходил маскирование полей обычных вызовов `Info`/`Infow` | Обёртка реализует `Check`; тестируются обычный и sugared logger |
| Отсутствующая настройка скрытия включала показ секретов | По умолчанию скрытие включено; явный `false` и старый ключ сохранены |
| Запуски в одну секунду могли перезаписать результаты дешифрования | Папка каждого запуска резервируется атомарно с уникальным суффиксом |
| Ошибки записи генератора терялись | Генерация останавливается и возвращает ошибку; тест имитирует отказ записи для обоих источников |
| Ошибки входных файлов/паролей могли возвращать успех | Пустые и частично неуспешные операции возвращают ошибку, успешные записи сохраняются |
| Повреждённые типы KDF-параметров могли вызвать panic в зависимости | Ошибка преобразуется в ошибку записи входного пакета; тестируется повреждённый keystore |
| Дешифрование не принимало JSONL-файлы генератора по их именам | Поддерживаются все `inputs/decrypt/*.jsonl` |
| `log_level` сбрасывался в операциях | Уровень передаётся из CLI во все операции |
| Неподдерживаемые regexp молча пропускались | Regexp валидируется при загрузке; исправлены README и исходный шаблон |
| `edges` без `side` ничего не находил | По умолчанию используется `any` |
| Пароли обрезались, Unicode-passphrase не нормализовалась | Сохраняются пробелы; добавлена NFKD, тест известного Ethereum-адреса и эквивалентных Unicode-строк |
| Документация обещала смену языка и недостаточно объясняла хранение мнемоник | Указаны фактический английский интерфейс, открытое хранение passphrase/ключа, приоритет паттернов и ограничения regexp |

Регрессионные проверки: `go test ./...`, `go vet ./...`, `go test -race ./...`. Сквозной тест шифрует тестовый ключ, дешифрует его с сохранением пробелов в пароле, проверяет неверный пароль и сохранность предыдущего результата. Тесты генерации проверяют сохранение совпадений и возврат ошибки записи. YAML-примеры README проверяются автоматически.

Для обновления с v1.0.0 прочитайте раздел о паролях и Unicode в README. Существующие файлы данных не изменяются. Локальные пользовательские конфиги не заменяются шаблонами из репозитория: ранее игнорировавшийся regexp с `\1` теперь нужно исправить вручную или выразить через `symmetric`/`edges`.

Границы проверки: ручной ввод скрытого пароля и Ctrl+C в окне Windows не автоматизированы; macOS не проверялась. `language` и старый пакет `pkg/i18n` пока не подключены к текущему CLI. Эта проверка не включает полный аудит сторонних зависимостей.
