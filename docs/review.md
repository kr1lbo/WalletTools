# Проверка кода и документации для v1.1.0

Проверены CLI, CPU-генератор, полный CUDA-поиск, компиляция regexp в GPU-маски,
деривация мнемоник, keystore, запись результатов, конфигурация, маскирование
логов, однофайловый EXE и workflow релиза. Пользовательские входные файлы в
проверках не использовались.

## CUDA

- Собран fat backend для архитектур NVIDIA `sm_75` и новее.
- Проверено извлечение встроенного helper из единственного EXE и контроль его SHA-256.
- На RTX 4080 выполнены реальные smoke-тесты `symmetric` и regexp.
- Найденные CUDA ключ, адрес и исходный паттерн независимо перепроверяются на CPU.
- При `gpu_enabled: true` CPU не генерирует дополнительные кандидаты.
- Все уникальные `specific`, `symmetric` и `regexp` запускаются одновременно; дубликаты объединяются.
- `final: false` продолжает соответствующую задачу, `final: true` отменяет весь поиск.
- Ошибки CUDA не маскируются автоматическим fallback на CPU.

Известные ограничения: каждая цель создаёт отдельный CUDA-процесс и расходует
собственную VRAM; `edges` и `case_sensitive: true` поддерживаются только CPU.
Regexp использует Go RE2 без backreference и lookaround. Для сложных выражений
GPU-компилятор имеет ограничение на число развёртываемых альтернатив.

## Остальные исправления, сохранённые из v1.0.1

- Секреты маскируются и в обычных, и в sugared-вызовах Zap.
- По умолчанию скрытие секретов включено; явный `false` и старое имя настройки поддерживаются.
- Каждый запуск атомарно получает отдельную папку результатов.
- Ошибки записи, входных файлов, паролей и повреждённых keystore возвращаются вызывающему коду.
- Дешифрование принимает `inputs/decrypt/*.jsonl` и отдельные JSON keystore.
- `log_level` передаётся во все операции.
- Regexp валидируется при загрузке YAML; `edges.side` по умолчанию равен `any`.
- Пароль сохраняет крайние пробелы, BIP-39 passphrase нормализуется в NFKD.

## Выполненные проверки

```text
go test ./...
go vet ./...
scripts/build-cuda.ps1 -Arch all
scripts/build-release.ps1 -Version v1.1.0
wallettools-windows-amd64.exe --version
```

Дополнительно выполнен запуск релизного EXE в каталоге без внешнего helper:
встроенный fat backend был извлечён, regexp найден на GPU, а результат принят
CPU-проверкой. GitHub Actions для тега `v1.1.0` успешно выполнил тесты, vet,
сборку, smoke-тест и публикацию Release Assets.

Границы проверки: ручной скрытый ввод пароля и Ctrl+C в окне Windows не
автоматизированы; macOS GPU не поддерживается, CPU-сборка проверяется CI.
`language` и пакет `pkg/i18n` пока не подключены к текущему CLI.
