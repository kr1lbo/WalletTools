## Скачать и запустить (Windows x64)

1. Скачайте **wallettools-windows-amd64.exe** из Assets ниже или ZIP с программой, README и лицензией.
2. Переместите EXE в отдельную папку с правом записи и запустите двойным щелчком. Установка Go не нужна.
3. При первом запуске автоматически появятся `configs/`, `inputs/` и `logs/`.
4. Настройте `configs/patterns.yaml` для поиска своих vanity-адресов. По умолчанию ищется префикс `beef` до первого совпадения.

Доступны генерация из приватных ключей и мнемоник, шифрование и дешифрование Ethereum keystore. Для остановки генерации нажмите Ctrl+C, для выхода из меню — Enter.

Для обновления замените только EXE: существующие конфиги и входные файлы сохраняются. Результаты в `logs/` могут содержать приватные ключи и мнемоники — храните их приватно.

`checksums.txt` содержит SHA-256 для EXE и ZIP. Версия: `./wallettools-windows-amd64.exe --version`. Другая папка данных: `./wallettools-windows-amd64.exe --data-dir "D:\WalletToolsData"`.
