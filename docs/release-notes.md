## Новое в v1.1.0

- Добавлен полноценный NVIDIA CUDA-поиск приватных ключей: secp256k1, Keccak и сопоставление выполняются на GPU.
- Одновременно поддерживаются все уникальные `specific` и `symmetric`-паттерны, включая связанные `X` и `Y`.
- Добавлена GPU-поддержка regexp: якоря, литералы, `.`, классы символов, группы, альтернация и квантификаторы.
- CUDA-движок встроен в основной EXE. Пользователю нужен только совместимый драйвер NVIDIA; CUDA Toolkit устанавливать не требуется.
- В конфиг добавлены `gpu_enabled`, `cuda_device`, `cuda_batch_size` и возможность указать внешний helper для разработки.
- Найденный GPU результат независимо перепроверяется на CPU перед сохранением.
- Добавлены воспроизводимая сборка CUDA backend и лицензия модифицированного ProVanity.

## Скачать и запустить (Windows x64)

1. Скачайте **wallettools-windows-amd64.exe** из Assets ниже или ZIP с программой и документацией.
2. Поместите EXE в отдельную папку с правом записи и запустите его. Go и CUDA Toolkit не нужны.
3. При первом запуске автоматически появятся `configs/`, `inputs/` и `logs/`.
4. Для NVIDIA GPU установите `gpu_enabled: true` в `configs/app.yaml` и настройте `configs/patterns.yaml`.

При `gpu_enabled: false` приватные ключи генерируются на CPU. Генерация мнемоник всегда выполняется на CPU. Для GPU требуется совместимая видеокарта NVIDIA и актуальный драйвер.

Regexp использует синтаксис Go RE2. Backreference (`\1`) и lookaround не поддерживаются. `checksums.txt` содержит SHA-256 для EXE и ZIP.
